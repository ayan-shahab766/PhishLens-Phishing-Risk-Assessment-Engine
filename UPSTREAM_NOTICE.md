# Upstream notice

This project began as a derivative of `Saadidream/Phishing-Email-Detection-System`.

The original project supplied the baseline text-classification concept, dataset layout, FastAPI service shape, and initial model artifacts. PhishLens adds explainable multi-signal triage, local audit metadata, analyst feedback, training evaluation, API hardening, Docker packaging, tests, documentation, and a new interface.
